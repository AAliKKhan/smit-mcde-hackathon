# Device clock drift analysis (Rule 11)

Generated by `transform/04_punches.py`.

## Method

1. Map punches to employees (Rule 8), keep mapped only.
2. For every employee-day take the **first punch** (check-in proxy).
3. Expected time = that calendar day's roster shift start (`shift_roster` joined by Monday-week).
4. `delta = first punch - expected start`; samples with delta outside [-120, +240] min are excluded (late-night spill, mis-attributed first punches).
5. Mean delta per device: a clock that is off shifts EVERY employee on that device by the same amount, while normal lateness cancels out in the mean.
6. `offset = -(device mean - median of the other devices)`; devices deviating >= 30 min are corrected (Rule 11).
